## 1. 登場人物と役割

| 役割 | 説明 |
|---|---|
| **取りまとめ担当**（HR担当者） | 全体ファイルを管理する。担当者の割り当て、分割エクスポート、マージ、上司名補完、最終確認を行う |
| **組織担当**（部門担当者） | 自分が担当する組織の after 欄を記入する。新任者の追加も担当する |

---

## 2. 担当者（assignee）の概念

### 2-1. 定義

各 `AllocationRow` に `assignee`（担当者名）フィールドを持つ。
- Excel **A列**（ヘッダーなし）から読み取る
- マスタ化しない。ファイル内の既存値をリスト化して運用する
- ツール内で変更・追加可能
- エクスポート時も A列に出力する

### 2-2. 担当者の決め方

担当者は **旧組織軸** を基本として取りまとめ担当が割り当てる。
出向者のように「現在の組織」と「担当すべき組織」が異なる場合は個別調整する。

```
例）
  人事部・人事課      → 人事部担当
  出向者組織（人事系） → 人事部担当（個別調整）
  技術部・開発課      → 技術部担当
  出向者組織（技術系） → 技術部担当（個別調整）
  新任者（prevDept なし）→ 組織担当が自分で設定
```

## 3. 業務フロー

### Step 1: 取りまとめ担当がExcelをインポート（管理者モード）

- Excel をインポートし **管理者モード** で開く
- A列に既存の担当者情報が入っている場合はそのまま読み込む

---

### Step 2: 担当者割り当てウィザード

取りまとめ担当が旧組織ツリーを見ながら担当者を自動割り当てする。

```
ウィザード Step 1: 分割軸を選択
  ┌─────────────────────────────────────────┐
  │ 担当者の分割単位を選択してください      │
  │                                         │
  │ ○ 統括部単位（部・Div レベル）          │
  │ ○ グループ単位（課・Section レベル）    │
  │ ○ 自由設定（組織ツリーで手動割り当て） │
  └─────────────────────────────────────────┘

ウィザード Step 2: 自動割り当てプレビュー確認・調整
  旧組織ツリーを表示し、選択した軸で自動提案した担当者割り当てを確認する。
  ドラッグまたはドロップダウンで組織ごとに担当者を変更できる。
  担当者名を新規入力すれば新しい担当グループを作成できる。

ウィザード Step 3: 出向者・例外の個別調整
  out-assignee の候補一覧（prevDeptCode と現在のdeptCode が異なる行）を表示し、
  担当者を手動で設定する。

ウィザード Step 4: 未割当行の確認
  assignee が空の行を一覧表示する（主に新任者・例外）。
  取りまとめ担当が手動で担当者を割り当てるか、「担当者未設定のまま配布」を選択する。

ウィザード Step 5: 確定
  担当者ごとの行数サマリーを確認して確定する。
```

---

### Step 3: 担当者ごとにExcelを分割エクスポート

- 管理者モードで担当者ごとの Excel を一括生成してエクスポートする
- 各ファイルの A列（担当者）はその担当者名で統一される
- 各組織担当に配布する

---

### Step 4: 組織担当が自分のExcelを編集（担当者モード）

各組織担当がファイルをインポートし **担当者モード** で開く。

```
担当者選択画面:
  ┌─────────────────────────────────────────────────────┐
  │ 担当者を選択                                         │
  │                                                     │
  │ [担当者で絞り込み ▾]  [組織名で検索 🔍]            │
  │                                                     │
  │ ▼ 人事部担当                           計102行 [選択]│
  │     人事部          100行                           │
  │     出向者組織        2行                           │
  │                                                     │
  │ ⚠ 未割当                               計  5行      │
  │     （担当者未設定行。新任者など）                   │
  └─────────────────────────────────────────────────────┘
```

**ワーニング条件**（操作は止めない。選択後に通知する）:
- 自分の担当者名以外の行が存在する → 「他の担当者の行があります」（参照可・担当変更可）
- 未割当行が存在する → 「担当者未設定の行があります」（新任者など、組織担当が設定）

**担当者モードの挙動**:
- 自分の担当行は通常通り編集可能
- 他の担当者の行はワーニング表示（参照用として閲覧可能。担当者を自分に変更することも可能）
- 新規行を追加すると `assignee` が自動的に選択中の担当者に設定される
- 新任者行（未割当）を見つけたら `assignee` を自分の担当者名に変更して記入する

**記入内容**:
- after 欄（組織・ポジション・等級等）を入力する
- 上司ポジション欄に **上司の氏名** を記入する（この時点では氏名のみ。IDは後で補完）

---

### Step 5: 記入済みExcelを返却

各組織担当が記入済みの Excel を取りまとめ担当に返却する。

---

### Step 6: 取りまとめ担当がマージ（管理者モード）

取りまとめ担当が返却されたファイルを順にインポート・マージする。
マージ時に担当者フィールド（A列）はそのまま取り込む。

---

### Step 7: 上司名自動補完（取りまとめ担当が実行）

マージ後、上司欄に氏名が記入されているが `managerPositionCode`（上司の positionCode）が未確定の行を補完する。

```
補完の仕組み:
  1. 記入された「上司名（managerName）」を全人員データと照合
  2. 一致候補をサジェスト表示（同姓同名の場合は組織情報で絞り込み）
  3. 取りまとめ担当が確認・選択 → managerPositionCode を確定
  4. 未解決の行は「上司名未解決」ワーニングとして残る
```

❓ 完全一致以外のあいまい検索（かな・漢字ゆれ）をどこまでサポートするか要確認。

---

### Step 8: 最終確認・エクスポート

- レビュー画面で変更種別ごとの件数・バリデーション問題を確認する
- 問題がなければ Excel エクスポートして保管する
- 将来的には SuccessFactors へ直接書き戻す（Phase 4/5）

## 4. 作業軸と照会軸

| 視点 | 用途 | 主な利用者 |
|---|---|---|
| **担当者軸** | 「自分の担当行だけ表示する」 | 組織担当 |
| **旧組織軸** | 「旧組織ごとの変更内容を確認する」 | 取りまとめ担当・審査 |
| **新組織軸** | 「新しい組織に誰が着任するか確認する」 | 取りまとめ担当・新任部門長 |
| **人軸** | 「田中さんはどこへ行ったか確認する」 | 人事・管理職 |

---

## 5. 組織継承マッピング

旧組織 → 新組織の対応づけは引き続き必要（after 初期値の設定に使用）。
「スコープ」概念は廃止し、担当者フィールドで代替する。

| パターン | 対応方法 |
|---|---|
| コード継続（多数派） | 自動検出（コード一致） |
| コード変更 | 手動対応づけ |
| 分割・統合・廃止 | 手動対応づけ＋個別割り振り |

組織継承マッピングは「after 初期化ウィザード」として管理者モードで提供する。
