# 6. レビューと Excel 出力

## レビュータブ

画面上部の **「レビュー」** タブを開くと、すべての変更内容を一覧で確認できます。

---

## サマリ（変更種別の集計）

レビュータブの左側に変更種別ごとの件数が表示されます。

```
変更サマリ
┌───────────────────────┐
│ 異動（組織間）   12件 │
│ 昇格             3件  │
│ 降格             1件  │
│ 兼務追加         5件  │
│ 本務出向         2件  │
│ 退職             1件  │
├───────────────────────┤
│ ⚠ 警告           4件  │
│ ❌ エラー         1件  │
└───────────────────────┘
```

件数をクリックすると、その種別の行だけにフィルタされた詳細一覧が表示されます。

---

## 変更一覧（AttributeGrid）

各行の before（旧）と after（新）の差分を表形式で確認できます。

- **赤字**: after で変わったフィールドの値（変更あり）
- 取り消し線: before の値

フィルタ機能：
- 「変更のみ」チェックで変更があった行だけ表示
- 変更種別チップをクリックで絞り込み
- 名前・ID・組織コードで検索

---

## バリデーション（問題タブ）

**エラー（❌）** と **警告（⚠）** の 2 種類があります。

### エラー

Excel 出力前に必ず解消が必要なもの。

| エラー例 | 対処 |
|---|---|
| 役職コードが有効な選択肢にない | 正しい役職コードを選び直す |
| 必須フィールドが未入力 | 該当フィールドを入力する |

### 警告

業務上の確認が必要だが、そのまま出力も可能なもの。

| 警告例 | 意味 |
|---|---|
| 上司が別の組織にいる | 出向者などは許容されるケースあり |
| バンドと給与等級の組み合わせが通常と異なる | 意図的ならそのままでよい |

### 警告の一括確認

警告はグループ単位で「全件 OK ✓」ボタンを押すと確認済みにできます。  
確認済みにしても Excel 出力には影響しません（出力には含まれます）。  
「なぜこれでよいか」の確認プロセスをチームで踏んだという記録になります。

---

## Excel 出力

画面右上の **「Excel 出力」** ボタンをクリックします。

### 出力される内容

- 変更のあった行のみ出力（変更なし行は出力しない）
- 各行に「移動区分」列が付く（異動・削除など）

### 出力形式オプション

| オプション | 説明 |
|---|---|
| 通常出力 | 全変更行を 1 つの Excel に出力 |
| 担当者別分割出力 | 担当者ごとにシートを分割（→ [07-split-merge.md](./07-split-merge.md)） |

---

## 出力前チェックリスト

Excel を出力する前に確認してほしいこと：

- [ ] エラーが 0 件になっている
- [ ] 警告をすべて確認した（または意図的に残した警告を把握している）
- [ ] サマリの件数が想定通り（多すぎる・少なすぎる変更がない）
- [ ] 比較モードで代表的な組織を目視確認した

---

## よくある質問

**Q. 変更なしの行も出力したい**  
A. 現在、変更ありの行のみ出力する設計です。全行出力が必要な場合は元の Excel を参照してください。

**Q. Excel 出力したあとで変更を加えてもいいですか？**  
A. ツール上での変更はいつでも Undo/Redo できます。出力した Excel は独立したファイルなので、ツール上での操作には影響しません。

**Q. エラーがあっても出力できますか？**  
A. 出力自体はできますが、エラーがある状態で提出するとシステム取り込み時に問題が発生する可能性があります。
