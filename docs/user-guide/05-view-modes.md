# 5. 表示モード切替

画面右上のコントロールで表示方法を変えられます。

---

## ツリー / コンパクト 切替

ヘッダーの **「ツリー」「コンパクト」** ボタンで切り替えます。

### ツリーモード（デフォルト）

```
┌──────────────────┐
│ 営業部           │
│  ├ 田中 部長     │  ← 上司・部下の階層が見える
│  │  ├ 佐藤 課長  │
│  │  └ 高橋 主任  │
│  └ 鈴木 課長     │
└──────────────────┘
```

- 上司・部下の関係が視覚的に分かる
- 階層が深いと縦に長くなる

### コンパクトモード

```
┌──────────────────┐
│ 営業部           │
│ 田中 M4  佐藤 M3 │  ← バンドが一目で見える
│ 高橋 M2  鈴木 M2 │
└──────────────────┘
```

- 全員のバンドが一覧で見える
- **バンドの調整（昇格・降格・M職P職切替）に最適**
- パネル間でバンドをドラッグして移動すると自動で昇格/降格フォームが開く

> **コツ**: バンドをそろえる作業はコンパクトモードでやると全体を見ながら進められます。

---

## 比較モード

ヘッダーの **「比較」** ボタンで有効になります。

画面が左右に分かれ、**旧組織（左）** と **新組織（右）** を並べて見られます。

```
┌──────────────┬──────────────┐
│ 旧: 営業1部  │ 新: 営業部   │
│  田中 部長   │  田中 部長   │ ← 同じ人がどちらにいるか
│  佐藤 課長   │              │ ← 旧には居たが新には居ない
│              │  高橋 課長   │ ← 新に加わった
└──────────────┴──────────────┘
```

- 組織再編の前後で誰がどこにいるかを確認したいときに使う
- 比較モード中は操作（ドラッグ・ダブルクリック）はできない

---

## 表示項目の変更

ヘッダーの **「表示項目」** ドロップダウンで各カードに表示する情報を変えられます。

| 表示項目の例 | 活用シーン |
|---|---|
| バンド | バンド構成の確認 |
| 給与等級 | 給与等級の整合性チェック |
| 異動事由 | 異動事由が正しく設定されているか |
| 兼務区分 | 兼務行の一覧確認 |
| 上司名 | レポートラインの確認 |

---

## 組織パネルの折りたたみ

各パネルはヘッダー左の **▾/▸** ボタンで折りたたみできます。

整理した後のパネルや、今回の改編で触らない組織は折りたたんでおくと作業しやすくなります。

---

## 展開/折りたたみ一括操作

ツリーモード時、パネルヘッダーに表示される **「すべて展開」「すべて折りたたみ」** ボタンで  
そのパネル内の階層を一括で開閉できます。

---

## 組織ツリーとキャンバスの連動

左サイドバーの組織ツリーで組織名をクリックすると、  
対応する組織パネルへキャンバスが自動スクロールします。

人数が多くパネルが見つけにくいときに使ってください。
