# 7. 分割出力とマージ（上級者向け）

複数の担当者が分担して配置作業を行い、最後に取りまとめる場合の手順です。

---

## 全体の流れ

```
取りまとめ担当
    ↓
1. Excel を読み込む
2. 担当者を各行にアサイン（担当者ウィザード）
3. 担当者別に分割して Excel を配布
    ↓
各担当者
4. 自分の担当範囲の Excel を読み込んで作業
5. 完成した Excel を取りまとめ担当に提出
    ↓
取りまとめ担当
6. 各担当者の Excel をマージ
7. 競合を解決
8. 最終出力
```

---

## 1〜3. 担当者アサインと分割

### 担当者のアサイン

管理者モードで操作します。各行の「担当者」フィールドに担当者名を設定します。

- 組織単位でまとめて設定可能（担当者ウィザード）
- 担当者が決まっていない行は「未設定」として残る

### 分割 Excel の出力

「担当者別分割出力」を選択すると、担当者ごとに別ファイルとして出力されます。

各担当者は自分の担当行だけが含まれた Excel を受け取ります。

---

## 4〜5. 担当者の作業

担当者はツールに自分の Excel を読み込んで作業します。

**担当者モードの特徴：**
- 自分の担当行のみ表示される
- 他の担当者の行は見えない（誤操作防止）
- 新規行を追加すると自動的に自分の担当者名がセットされる

### 上司が別のファイルに分断されている場合

Excel が組織単位で分割されているため、**上司が自分のファイルに存在しない**ケースが発生します。

```
例: Aファイル（Org A 担当）
  田中 managerPositionCode=P_BOSS  ← P_BOSS は Bファイルの山田部長
  鈴木 managerPositionCode=P_BOSS

Bファイル（Org B 担当）
  山田（P_BOSS） ← Aファイルには入っていない
```

このとき、Aファイルを単独で読み込むと田中・鈴木のカードに  
**`↑ 山田部長 (別組織)`** というインジケーターが表示されます。

- **青テキスト `(別組織)`**: マージ後に解決できる見込みがある（マージすると正しい階層で表示される）
- **黄テキスト `(上司不明⚠)`**: 全ファイルをマージしても対応する上司行が見つからない

このインジケーターが表示されていても操作は続けられます。保存エラーにはなりません（警告のみ）。  
マージ後に上司行が結合されると、インジケーターは自動的に消えて正しい階層で表示されます。

---

## 6. マージ

取りまとめ担当が各担当者から受け取った Excel を順番にマージします。

「マージ」ボタンから Excel ファイルを選択すると、現在の状態に対して変更が取り込まれます。

---

## 7. 競合の解決

同じ行を複数の担当者が変更していた場合、競合が発生します。

```
競合の例:
  担当者 A: 田中さんを「営業1部」に異動
  担当者 B: 田中さんを「営業2部」に異動
  → どちらを採用するか選ぶ必要がある
```

競合解決ダイアログでは：
- 取り込み前の値（before）
- 担当者 A の変更内容
- 担当者 B の変更内容

を並べて表示し、どちらを採用するかを 1 件ずつ選択します。

### 競合の種類

| 競合の種類 | 対処 |
|---|---|
| 同一フィールドへの異なる変更 | どちらか一方を選択（またはどちらも不採用） |
| 一方が行を削除、他方が変更 | 削除を優先するか変更を優先するか選択 |
| 新規行の追加（両者） | 両方を追加（rowId が重複しないため通常は競合しない） |

---

## よくある質問

**Q. 担当者は何人まで設定できますか？**  
A. 人数制限はありません。ただし担当者が多いほどマージ時の競合管理が複雑になります。

**Q. マージの順番は関係しますか？**  
A. 同じ行を複数の担当者が変更している場合、後でマージしたファイルが優先されます（競合ダイアログで上書き）。重要な変更を持つファイルは最後にマージすることを推奨します。

**Q. マージを間違えた場合は？**  
A. Undo で戻せます。マージ操作全体を 1 ステップとして Undo できます。

**Q. 担当者が誤って他の人の行を変更した場合は？**  
A. マージ時に変更一覧を確認してから取り込めるため、想定外の変更を発見できます。取り込まない選択も可能です。

---

## 注意事項

- 分割後に取りまとめ側で行を追加・削除した場合、担当者との行番号がずれることがあります。マージ前に取りまとめ側の作業は最小限にとどめることを推奨します。
- 担当者の Excel を他の担当者と共有しないでください。個人情報（給与等級など）が含まれる場合があります。
