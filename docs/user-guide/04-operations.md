# 4. 業務操作カタログ

カードをダブルクリックして開く操作パネルから実行できる業務操作の一覧です。

> すべての操作は Undo できます。迷ったら試してみてください。

---

## 操作の種類

### 異動（組織間移動）

別の組織への異動を記録します。

- 異動事由を選択（必要に応じて）
- 部下がいる場合：部下を一緒に移動するか、上司関係を外すかを選べる
- 元のポジションを「空席として残す」オプションあり

**ドラッグ操作でも可能**: カードをつかんで別組織パネルへドロップ。

---

### 昇格 / 降格

ポジションバンドの変更を記録します。

- 昇格マトリクス（Excel の BT〜BW 列）が読み込まれている場合は役職の候補を自動提案
- バンド変更に伴い給与等級が自動導出される
- 給与等級が変わる場合はポジション変更が必要（フォーム内「変更」ボタンから対応）

**簡易モード**: バンドと役職名だけ入力すれば他の項目は自動設定される。

---

### M職P職切替

給与等級を変えずに管理職（M職）と専門職（P職）を切り替えます。

- M職P職切替マトリクス（Excel の BX〜CA 列）が読み込まれている場合は候補を自動提案
- **M職 → P職のとき**: 部下がいる場合「上司のまま残す」か「上司から外れる」かを選択
- **P職 → M職のとき**: 通常は部下がいないため確認不要

---

### 役職名変更

昇降格を伴わない役職名（フリータイトル）の変更。  
役職を選ぶとフリータイトルが自動提案されます。

---

### 兼務追加

別の組織で追加の役割（兼務）を記録します。

- 兼務先の組織・役職を指定
- 兼務理由の入力（任意）
- 兼務行は本務行とは別の行として管理される

**ドラッグ操作でも可能**: カードを別組織へドラッグ → ダイアログで「兼務」を選択。

---

### 本務出向

グループ会社・関係会社への出向を記録します。

**SF 連携あり（社内の出向者用組織へ）**:
1. 出向先組織をキャンバスに追加
2. カードをドラッグしてドロップ → 出向として処理

**SF 連携なし（社外への出向）**:
1. 出向元行の更新 + 出向先受入行の新規作成を一括で行う
2. 出向先会社名を入力

---

### 本務出向解除 / 受入解除

出向から戻る際の操作。出向前の組織に戻すかどうかを選べます。

---

### 休職

休職フラグをセットします。

- 休職フラグがセットされると、その行は「休職中」として扱われる
- 取り消し操作（「休職取消」）でフラグを外せる

---

### 退職

ポジションと在席者の両方を削除します。

- Excel 出力時: 移動区分＝「削除」として出力される
- Undo でいつでも元に戻せる

---

### 4/1 不在（退職・移籍）

**4/1 時点で在籍していない人**（3月末退職・4/1付移籍）を一時的に管理する機能です。  
操作パネルからではなく、**フローティングパネル「4/1 不在」** を使います。

#### 4/1 不在への登録

1. キャンバスヘッダーの **「4/1 不在」ボタン**をクリックしてパネルを表示
2. 対象者のカードをつかんでパネルにドロップ
3. ダイアログで **「退職」または「移籍」** を選択（メモも入力可）
4. 確定するとカードがパネルに移動し、組織ツリーから消える

| 種別 | 意味 | 異動事由（自動設定） |
|---|---|---|
| 退職 | 3月末までに退職・解任済み | 【対応なし】3月末までに退職／解任済み |
| 移籍 | 4/1付で他社へ移籍 | 【個別】4/1付移籍 |

#### 不在パネルからの復帰

間違えて不在登録した場合は、パネル内のカードをつかんで組織パネルへドロップすると元の組織に戻ります。  
異動事由がクリアされ、通常の在籍行として復元されます。

#### 注意事項

- 不在登録後も **Undo で元に戻せます**
- 部下がいる場合、不在登録後に部下が「上司なし」状態になります（カードに `↑ 別組織` または `↑ 上司不明` が表示されます）  
  → 部下の移動先を別途設定してください（AIチャットに「○○さんの部下の上司を△△部長に変更して」と依頼できます）
- 休職とは異なります。休職者は引き続き組織に在籍したままです

---

### ポジション操作

| 操作 | 内容 |
|---|---|
| 空席として残す | 在席者をポジションから外し、空席行を残す |
| ポジション削除 | 空席ポジションをリストから除去 |
| 上司設定 | ポジションの上司を変更（ドラッグでも可） |

---

## 操作が表示されない場合

操作パネルに特定の操作が出てこない場合、その行の条件が合っていない可能性があります。

よくあるケース：

| 操作が出ない | 理由 |
|---|---|
| 昇格・降格 | 在席者がいない（空席ポジション） |
| 兼務追加 | すでに同じ組織で兼務中 |
| M職P職切替 | 昇降格マトリクスに該当エントリがない |
| 出向解除 | 出向フラグが立っていない |

操作名の横に理由が表示されるので確認してください。
