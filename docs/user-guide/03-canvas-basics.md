## 未割当の人を配置する

マッピング後に左下「未割当」エリアに人が表示されます。  
これらは **どの組織にも属していない状態** です。順番に配置していきます。

### 方法 A：ドラッグ&ドロップ

1. 左下の未割当カードをつかむ
2. キャンバス上の組織パネルへドロップ

ドロップ時に「異動」「兼務」などの選択肢が出る場合があります。

### 方法 B：ラジオボタンで選択して一括移動

1. 左サイドバーで人を選択（複数選択可）
2. 「組織移動」ボタンで移動先を選ぶ

複数の人を同じ組織へ一度に動かしたいときに便利です。

## 組織パネルの操作

### ＋ボタンで空席ポジションを追加する

組織パネルの上部にある **＋** ボタンを押すと、その組織に新しい空席ポジションが作成されます。  
ポジションコードは自動採番され、ダブルクリックで役職名・バンドなどを入力できます。

### パネルを追加する

左サイドバーの「パネルタブ」から、表示したい組織を追加できます。  
最初は全組織は表示されていません。必要な組織だけを選んでキャンバスに並べます。

### パネルを並び替える

パネルのヘッダーをドラッグして並び替えられます。

## ドラッグ操作

### 人を別の組織へ移動する

人カードをつかんで別の組織パネルへドロップ → 「異動」「兼務追加」などの選択ダイアログが出る。

**部下ごと移動したい場合：**  
ダイアログに「部下ごと移動」の選択肢が表示されます（その人に直属の部下がいる場合）。

### 上司を変更する

ポジションカードをつかんで、別のポジションカードの上へドロップ → 上司変更が確定する。

> ループ（A の上司が B、B の上司が A）は自動チェックで防止されます。

### 兼務を追加する

人カードをつかんで別組織へドロップ → ダイアログで「兼務」を選択。

## 左サイドバーの使い方

### 組織タブ

- **組織ツリー**: 組織の階層を展開して特定の組織を探せる。クリックするとそのパネルへスクロール。
- **人物一覧**: 全員のリスト。名前検索で絞り込み、クリックで該当カードをハイライト。

### パネルタブ

- **パネル一覧**: キャンバスに表示中の組織パネル一覧。ここから表示/非表示を切り替える。
- **未割当**: どの組織にも属していない人の一覧。
- **未設定**: ポジションはあるが担当者が設定されていない行。

## キーボード操作

| キー | 動作 |
|---|---|
| Ctrl+Z | 操作を元に戻す（Undo） |
| Ctrl+Y | 操作をやり直す（Redo） |
| Esc | 選択解除 / モーダルを閉じる |
