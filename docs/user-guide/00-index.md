# 人員配置ツール — ユーザーガイド

組織改編・異動計画を Excel ベースで行うための社内ツールです。  
「旧組織の Excel を読み込み → 新組織への配置を決め → 差分 Excel を出力する」が基本の流れです。

## クイックスタート（5 分）

初めて使う場合はこの順番に進んでください。

```
1. Excel を読み込む（またはサンプルデータを使う）
        ↓
2. 旧→新 組織マッピングを確認する  → [02-org-mapping.md]
        ↓
3. 未割当の人を新しい組織へ配置する → [03-canvas-basics.md]
        ↓
4. ダブルクリックで異動・昇格などを記録する → [04-operations.md]
        ↓
5. サマリタブで変更を確認する       → [06-review-export.md]
        ↓
6. Excel に出力する                 → [06-review-export.md]
```

## ショートカット早見表

| 操作 | 方法 |
|---|---|
| 人を別の組織へ移動 | カードをドラッグ → 組織パネルへドロップ |
| 上司を変更 | ポジションカードをドラッグ → 上司カードへドロップ |
| 昇格・兼務などのメニューを開く | カードをダブルクリック |
| 空席ポジションを作成 | 組織パネルの **＋** ボタン |
| 表示をまとめる（バンド操作向け） | ヘッダーの **コンパクト** ボタン |
| Undo / Redo | Ctrl+Z / Ctrl+Y（または画面右上の矢印） |
