# G5-01 GitHub Actions 自動コーディング仕様

> **目的**: GitHub Issue から Claude Code が自動でコード変更・PR作成するワークフローを定義する。
> **位置づけ**: ローカルでの対話開発が主（Primary）、GitHub Actionsは補助（Secondary）。
>
> **ユースケース**:
> - バリデーションルール追加（G2-02の1ルール → validateRow.ts）
> - マスタのワイヤー追加（G3-01のP1タスク）
> - フィールドの入力種別変更
> - ドキュメント更新

---

## 1. ワークフロー設計

### 1.1 トリガー条件

```yaml
on:
  issues:
    types: [labeled]
  issue_comment:
    types: [created]
```

- Issue に `claude-task` ラベルを付けたとき実行
- または Issue に `/claude run` コメントを付けたとき実行

### 1.2 実行フロー

```
1. Issue本文を読む
2. 関連するspec（G1〜G4）を読む（Issue本文で指定）
3. CLAUDE.mdを読む
4. 対象ファイルを特定・編集
5. ブランチ作成（claude/issue-{number}）
6. PR作成（Issue番号をリンク）
7. 型チェック実行（npx tsc --noEmit）
8. 型エラーがあればPRに追記して修正
```

## 3. GitHub Actions ワークフローファイル（雛形）

```yaml
# .github/workflows/claude-task.yml
name: Claude Code Task

on:
  issues:
    types: [labeled]

jobs:
  claude-code-task:
    if: github.event.label.name == 'claude-task'
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: write

    steps:
      - uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20'

      - name: Install dependencies
        run: npm ci

      - name: Install Claude Code
        run: npm install -g @anthropic-ai/claude-code

      - name: Run Claude Code
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
          ISSUE_NUMBER: ${{ github.event.issue.number }}
          ISSUE_TITLE: ${{ github.event.issue.title }}
          ISSUE_BODY: ${{ github.event.issue.body }}
        run: |
          BRANCH="claude/issue-${ISSUE_NUMBER}"
          git checkout -b "$BRANCH"
          
          claude --print "
          GitHub Issue #${ISSUE_NUMBER}: ${ISSUE_TITLE}
          
          ${ISSUE_BODY}
          
          以下の手順で実装してください:
          1. CLAUDE.mdを読む
          2. Issue本文で指定されたspecファイルを読む
          3. 対象ファイルを読んで実装する
          4. 実装後、specファイルの実装状況を更新する
          5. npx tsc --noEmit で型チェックを実行し、エラーがあれば修正する
          "
          
          git config user.name 'Claude Code Bot'
          git config user.email 'claude-bot@anthropic.com'
          git add -A
          git commit -m "feat: resolve issue #${ISSUE_NUMBER} via Claude Code"
          git push origin "$BRANCH"

      - name: Create Pull Request
        uses: peter-evans/create-pull-request@v6
        with:
          title: "feat: #${{ github.event.issue.number }} ${{ github.event.issue.title }}"
          body: |
            Closes #${{ github.event.issue.number }}
            
            🤖 Generated by Claude Code via GitHub Actions
          base: main
          labels: claude-generated
```

## 4. ローカル実行（主要な使い方）

```bash
# ローカルでIssueを確認してから実行
gh issue view 42

# Claude Codeに直接指示（対話的）
# → このコンソールでそのまま指示する（現状の方法）

# または --print で非対話的に実行
claude --print "
Issue #42の内容: ...
specs/G2-domain/02-validation-rules.md を読んでV04を実装してください。
"
```

## 注意事項

- GitHub Actions の Ubuntu runner で `claude` CLIが動作するか確認が必要
- API コストは Actionsの実行ごとに発生する（1回あたり概算: $0.05〜$0.5）
- PRは必ず人間がレビューしてマージする（自動マージは禁止）
